## 2. Database & Persistent Storage Strategy (Render)
Render's default container filesystem is **ephemeral** (wiped on every redeploy or restart):
- **Structured Data (Devices, Enrollment Tokens, Telemetry, Events, Incidents, Audit Logs, Users, Settings)**:
  - Stored persistently in **Render Managed PostgreSQL** (`DATABASE_URL` env var).
  - `backend/database.py` automatically switches to `psycopg2` when `DATABASE_URL` is present, creating all tables on startup.
- **FAISS Semantic Vector Index**:
  - **Automatic DB Rebuild (Zero extra cost)**: On startup, `PersistentLiveVectorStore.rebuild_from_db_if_empty()` automatically rebuilds the FAISS index from events persisted in PostgreSQL if no local index file exists.
  - **Optional Paid Persistent Disk (Faster restarts at large scale)**: On a Render **Starter** (or higher) Web Service, attach a Render Disk mounted at **`/var/data`** and set `MONITOR_FAISS_DIR=/var/data/faiss_live`.

## 3. Exact Render Service Settings (Backend)

You can deploy automatically via **`render.yaml`** (Blueprint) OR manually:

### Option A: Deploy via `render.yaml` Blueprint (Recommended)
1. Log in to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** -> **Blueprint**.
3. Connect your GitHub repository and select branch **`main`**.
4. Render detects `render.yaml` (`ai-monitor-db` PostgreSQL + `ai-monitor-backend` Web Service).
5. When prompted for `sync: false` secrets, enter:
   - `MONITOR_ADMIN_PASSWORD`: A strong login password for the `admin` dashboard user.
   - `CORS_ALLOWED_ORIGINS`: Your Streamlit dashboard URL (e.g. `https://<your-app>.streamlit.app`), or update right after deploying Streamlit.
6. Click **Apply** to create and deploy both services.

### Option B: Manual Render Web Service Settings
- **Service Type**: Web Service
- **Runtime**: `Python 3` (`.python-version` pins `3.11.11`)
- **Branch**: `main`
- **Instance Plan**: **Starter (512 MB+ RAM)** recommended *(PyTorch CPU + `all-MiniLM-L6-v2` + FastAPI require ~450–650 MB RAM; Free tier 512 MB can hit OOM under heavy load)*
- **Build Command**:
  ```bash
  pip install --upgrade pip && pip install --extra-index-url https://download.pytorch.org/whl/cpu -r requirements.txt
  ```
- **Start Command**:
  ```bash
  uvicorn backend.server:app --host 0.0.0.0 --port $PORT
  ```
- **Health Check Path**:
  ```text
  /health
  ```

### Required Render Environment Variables
| Variable | Value / Source |
|---|---|
| `PYTHON_VERSION` | `3.11.11` |
| `DATABASE_URL` | Internal Connection String from Render PostgreSQL (`ai-monitor-db`) |
| `MONITOR_ADMIN_KEY` | Strong random secret (auto-generated by `render.yaml`) |
| `MONITOR_JWT_SECRET` | 48+ char random secret (auto-generated by `render.yaml`) |
| `MONITOR_ADMIN_USER` | `admin` |
| `MONITOR_ADMIN_PASSWORD` | Your chosen strong admin password |
| `CORS_ALLOWED_ORIGINS` | `https://<your-streamlit-app>.streamlit.app` |
| `DEVICE_OFFLINE_SECONDS` | `30` |
| `OPENBLAS_NUM_THREADS` | `1` |
| `OMP_NUM_THREADS` | `1` |
| `MKL_NUM_THREADS` | `1` |
| `TOKENIZERS_PARALLELISM` | `false` |

Verify deployment by visiting:
`https://<your-render-service>.onrender.com/health`
Expected response: `{"status": "ok", "database": "postgresql", ...}`

## 4. Configure Streamlit Community Cloud (Dashboard)
1. Go to [Streamlit Community Cloud](https://share.streamlit.io/) -> **Create app** -> **From existing repo**.
2. Select:
   - **Repository**: `<YOUR_USERNAME>/<YOUR_REPO>`
   - **Branch**: `main`
   - **Main file path**: `app.py`
3. Click **Advanced settings...** -> **Secrets** and add:
   ```toml
   BACKEND_URL = "https://<your-render-service>.onrender.com"
   ```
4. Click **Deploy!**
5. Once deployed, copy your Streamlit app URL (e.g. `https://your-app.streamlit.app`), go back to Render -> `ai-monitor-backend` -> **Environment**, and set `CORS_ALLOWED_ORIGINS` to that exact URL (no trailing slash).
6. Sign in on the Streamlit dashboard using `username = admin` and your `MONITOR_ADMIN_PASSWORD`.

## 5. Enroll & Connect Windows 10/11 PCs Anywhere Over the Internet
1. Sign in to your deployed Streamlit Dashboard -> **🔧 Fleet Enrollment & Device Admin**.
2. Enter a Label and Client Organization, set **Server Address Reachable by Remote PCs** to `https://<your-render-service>.onrender.com`, and click **🔑 Generate Enrollment Token**.
3. On each target Windows 10/11 PC:
   - Ensure Python 3.10+ is installed.
   - Extract `dist/windows-monitoring-agent.zip`.
   - Run PowerShell:
     ```powershell
     .\installer\install_agent.ps1 -BackendUrl "https://<your-render-service>.onrender.com" -EnrollmentToken "<TOKEN>" -ClientOrg "ClientOrgName"
     ```
   - Type `YES` to authorize monitoring.
   - *(Use `-InstallAsService` in an Administrator PowerShell prompt to run as a native Windows Service `EnterpriseAIMonitorService`.)*
